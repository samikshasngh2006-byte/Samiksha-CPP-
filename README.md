## 🚀 How to Run the Programs

1. Clone this repository:

   ```bash
   git clone https://github.com/samikshasngh2006-byte/Samiksha-CPP-.git
   ```

2. Open the project folder in your code editor.

3. Compile any C++ program:

   ```bash
   g++ practical01.cpp -o practical01
   ```

4. Run the program:

   ```bash
   ./practical01
   ```
